# Pink Sky — Nuit skybox resource pack

A custom Minecraft skybox for the [Nuit](https://modrinth.com/mod/nuit) mod
(formerly FabricSkyboxes): a pink sky with a thick deck of pink clouds, with the
three supplied portraits standing in it — **one in front of you (north), two
behind you (south)**.

`PinkSky.zip` is the finished pack. Everything in it is generated by
`generator/build_pack.py` from the three photos in `generator/source_photos/`.

## Installing

1. Install **Nuit** (Fabric or NeoForge) — the pack does nothing without it.
2. Drop `PinkSky.zip` into `.minecraft/resourcepacks/`.
3. In game: *Options → Resource Packs* → enable **Pink Sky**.

The skybox is limited to the Overworld and hides itself underwater.

## Which way am I looking?

| Direction | What you see |
|-----------|--------------|
| North (`-Z`, F3 shows `Facing: north`) | photo 1, on her own |
| South (`+Z`) | photos 2 and 3 |
| East / west / up / down | pink sky and cloud |

Spawn facing north and she is straight ahead; turn around for the other two.

## Layout of the texture

Nuit's `square-textured` type reads one texture as a 3×2 grid of cube faces. The
face order is taken from `Utils.TEXTURE_FACES` in the Nuit source, not guessed:

```
row 0:  bottom | top   | south
row 1:  west   | north | east
```

`pink_sky.png` is 4608×3072, so each face is 1536×1536 — roughly 1:1 with a
1080p screen at normal FOV, so it stays sharp when you look straight at it.

## Rebuilding / tweaking

```sh
pip install Pillow numpy
python3 generator/build_pack.py     # ~90 s, rewrites PinkSky/ and PinkSky.zip
```

Useful knobs at the top of `build_pack.py` and in `main()`:

| What | Where |
|------|-------|
| Resolution per face | `FACE` (1536) |
| How big the girls are | the `fit_height(..., int(FACE * 0.46))` calls in `main()` |
| Where they stand | the `0.50, 0.62` style arguments — fractions of the face, second value is where their feet land |
| Sky colours | `SKY_STOPS` |
| Cloud colours | `CLOUD_RAMP` |
| Cloud amount | `cover=` in `render_face` — lower means more cloud |
| Cloud size | the `cells` argument — lower means bigger cloud masses |
| Sun direction | `LIGHT` |

A different cloud pattern with the same settings: change `SEED`.

`generator/preview/` holds flat PNGs of each face from the last build, so you
can check a change without launching the game.

## How it is generated

- **Portraits.** Cropped to their alpha, edge colours bled outward so the
  resampler cannot drag the transparent black into a halo, upscaled 3× with
  Lanczos, two-pass unsharp mask, a mild contrast/saturation grade, a tightened
  matte, and a touch of the sky's pink mixed in so they sit in the scene. The
  bottom of each cut-out fades out, so the hard crop of the original photo never
  shows.
- **Sky.** A vertical colour ramp driven by the view direction.
- **Clouds.** Each view ray is intersected with a horizontal plane, which is what
  makes a cloud deck converge towards the horizon. Two decks (a ceiling above, a
  sea below) plus a near bank at the girls' feet. Density is fractal noise; the
  part above the coverage threshold is treated as the height of a billowing dome
  and its surface normal is lit, which is what gives the clouds their volume.
  The finer noise octaves fade out towards the horizon, where a deck compresses
  past pixel size and would otherwise alias into moiré.
- **Seams.** Every part of the sky is a function of the view direction alone, so
  the six faces agree at their edges by construction. Measured seam error around
  the horizon ring is under 0.8/255.
